# Learning collection — historical pilot record

**Document type:** history of the 4–5 October 2026 pilot, not live selection status. [Türkçe](LEARNING-COLLECTION.md). Current rules: [selection](SELECTION.en.md), [evaluation](EVALUATION.en.md), and [architecture](ARCHITECTURE.en.md).

Motion Pad and Metaballs were the first two browser-observed examples with real screenshots. A later 21-record interim collection added 19 open-source projects reviewed through READMEs and GitHub metadata. Stars/forks were dated totals, not ratings or growth. Most of those additions had no live interaction test. Exercises and source links were proposed learning material, not verified complete courses or the builders' original prompts/stacks.

The catalog later grew to 23 records, and `lib/selection.ts` introduced five gates. The 5 October code-derived snapshot was **five selected / 18 review archive**, subject to review aging. Homepage defaults to the **Feed** tab, with **Learn from this** separate. `/candidates` is a capped review view for unselected discoveries, not the previous 24 hours; `/builds` is the deduplicated archive. Ingestion never promotes a candidate into a lesson.

An earlier pilot accepted user ratings and source suggestions on lesson pages. Those visitor forms were removed on 5 October. A private legacy server action and inbox data may remain, but they are not an active visitor flow or automatic validation. Old tests only establish behavior at their dated run.

Keep demo observation, README reading, builder statements, and Radar interpretation separate. A still preview is not proof of live animation. AI use in a product is not proof of AI-assisted development. Motion Pad/Metaballs have builder statements despite falling outside the current selected gate. Radar's adaptation proposal is not original source code or method. YouTube links alone do not prove a video was reviewed; transcript/comment analysis is not connected.
